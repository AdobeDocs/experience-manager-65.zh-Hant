# PDF Generator備份限制 {#pdf-generator-backup-limitations}

PDF Generator用來轉換檔案的暫存目錄無法備份。 即使服務已正確還原，資料仍可能會遺失，因為PDF Generator會依設定的時間間隔檢視及清除臨時目錄的內容。
